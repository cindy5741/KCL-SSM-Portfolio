data preprocessing
1. 若有很多筆裁決中心類別資料在不同xlsx檔案上 使用python merged_original_data.py 來合併成merged_original_data.xlsx
1. 將merged_original_data.xlsx 丟入跑python merge_data.py生出final_merge_data_100_label.xlsx / (center_usual_questioin_250519.xlsx)
2. 跑python cutallcolumns.py 將知識編號、標準問句、問題拆開 生出after_center_usual_questioin.xlsx
3. 路徑切到Train_model資料夾內 跑python preprocess.py
4. 在Train model資料夾內會輸出一個data的資料夾 裡面有 train、test、val.tsv
5. 要另外在Train model資料夾內的data資料夾生出all_data label.tsv 和 questin to label.tsv
5.1 跑python cut_for_all_data_label.py 輸出all_data_label.tsv
5.2 跑python cut_for_question_to_label.py 輸出question to label.tsv
6. 跑python split_class.py(為了new_all_data_label.tsv)

Training
1. (先去hyperparameter.py調整)
2. 重複上面把CL跑好 python run_train.py
2.1 要先跑CLBERT，才能用clbert模型行跑CLCE
2.2 CLBERT num_class=trainng data number、CLCEBERT=classification class number+1
3. 去pipeline_para.py調整model_name
3. python pipeline.py
4.生出result.tsv
